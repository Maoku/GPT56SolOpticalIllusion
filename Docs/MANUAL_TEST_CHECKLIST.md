# PARALLAX 手動確認チェックリスト

現行版は `/`、PARALLAX 2.0 は `/?museum=v2` で確認する。Phase 6の公開判断までは現行版を既定のまま維持する。

## デスクトップ

- [ ] Chrome / Edge / Safari / Firefox の対象バージョンでタイトルから入館できる
- [ ] WASD、矢印、マウス視点、Pointer Lock 解除が機能する
- [ ] 現行10展示とV2の12展示へ到達でき、背後や遠方の展示はフォーカスされない
- [ ] 各展示で操作、ヒント、答え合わせ、錯視へ戻る、リセットが機能する
- [ ] V2の6空間展示で鑑賞点移動、状態比較、結果記録、離脱が機能する
- [ ] 設定、ヒント、マップ、パスポート内で Tab が循環し、Esc で元の操作へ戻る
- [ ] 再読み込みと再訪後もversioned localStorageから進捗・結果・設定が復元される
- [ ] 4軸パスポートが順位や診断を示さず、SVG保存と共有キャンセルが安全に完了する
- [ ] マップから12展示を直接開け、URLに `museum=v2` と展示IDが残る
- [ ] コンソールに JavaScript エラーと未処理 Promise rejection がない

## モバイル

- [ ] 375 px 幅と横向きで UI が重ならない
- [ ] 左移動ボタンと右側ドラッグ視点を同時に操作できる
- [ ] 各操作対象が44 px以上あり、安全領域内に収まる
- [ ] 低品質で30 fps以上を維持し、発熱時も操作を継続できる
- [ ] モーション軽減で連続運動が停止し、6空間展示を静止状態で比較できる

## リリース

- [ ] 本番URLの直接アクセスと再読み込みが成功する
- [ ] gzip/Brotli後の転送量が5 MB以下
- [ ] 代表視点のスクリーンショットで壁、床、展示枠の欠落がない
- [ ] Chromium desktop / mobile のV1回帰とV2 12展示E2Eが全件成功する
- [ ] `Docs/PERCEPTUAL_VALIDATION.md` を5人以上で実施し、2展示とも4/5以上を満たす
