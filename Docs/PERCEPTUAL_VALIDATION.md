# オリジナル展示 知覚検証シート

「視差の花」と「色彩残響回廊」の初期設定を選ぶための観察テスト手順。これは知覚現象の科学的証明ではなく、展示として意図が伝わるかを確認するものです。

## 実施条件

- 制作に参加していない5人以上へ個別に実施する。
- ヒントと答え合わせは、最初の観察回答が終わるまで見せない。
- ディスプレイ、ブラウザ、画面輝度、モーション軽減設定を記録する。
- 体調不良や眼精疲労を感じた参加者は直ちに中止できる。
- 色覚や視覚特性は回答を評価する目的では使わず、本人が共有を望む場合だけ補足として記録する。

## 視差の花

標準候補値: 花弁数 `10`、層の位相 `28°`、視点追従量 `52%`。

1. ヒントなしで10秒観察する。
2. 視点スライダーを左右へ2往復する。
3. 「花弁に奥行き、呼吸、または層のずれを感じたか」を自由回答で聞く。
4. パラメーターを調整し、最も効果が明確な値を記録する。
5. 答え合わせを見せ、三層の同半径図形が移動している構造を理解できたか確認する。

## 色彩残響回廊

標準候補値: 順応色 `シアン`、注視時間 `6秒`。

1. 中央を注視し、無彩色へ切り替わってから色の有無を自由回答で聞く。
2. 気分不良がないことを確認し、必要なら別の順応色で再試行する。
3. 比較画面を見せ、順応色・無彩色・補色の関係を理解できたか確認する。

## 合格判定

各展示について5人中4人以上が意図した変化をヒントなしで報告できた設定を標準値に採用する。未達の場合は記録した有効範囲を基に既定値を変更し、別の5人で再実施する。
