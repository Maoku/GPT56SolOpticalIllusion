# PARALLAX 2.0 知覚検証・公開判定シート

このシートは、3D 空間展示の意図が説明なしで伝わるかを判定するための実施記録である。知覚現象の科学的証明、視力検査、診断には使用しない。

## 現在の判定

- 自動検証: interaction anchor、シーン状態、固定視点、reduced-motion、HUD 配置を `npm run test:e2e:spatial` で検証する。
- 人による知覚検証: **未実施**。
- 公開判定: **保留**。V2 は既定だが、下記の6展示を制作に参加していない5人以上で実施し、各展示 4/5 以上を満たすまで公開検証完了とは見なさない。

自動検証の成功は、人が錯視を知覚できたことの代替にはならない。

## 対象展示と成立契約

## 実施条件

- 制作に参加していない5人以上へ、1人ずつ実施する。
- ヒント、詳細解説、パスポートは最初の自由回答が終わるまで開かない。
- 同じビルド、固定 viewport、端末、ブラウザ、画面輝度、品質設定を記録する。
- 最初は標準モーションで行い、該当者または希望者は reduced-motion 代替でも実施する。
- 気分不良、眼精疲労、読みにくさがあれば直ちに中止する。
- 色覚や視覚特性は評価目的に使わず、本人が共有を望む場合だけ補足する。

## 1展示ごとの手順

1. 展示室へ入り、操作説明を読み上げずに観察を開始する。
2. 来館者が自力で主行為を開始できるか、UI ボタンを探した回数と開始までの秒数を記録する。
3. 変化を初めて報告した時点の秒数を記録する。
4. 「何が、どのように変わりましたか」と自由回答を得る。誘導する選択肢は出さない。
5. 一行ヒントを表示して再試行し、回答の変化を記録する。
6. 種明かしを見せ、原理を一文で説明してもらう。
7. UI が作品を遮ったか、操作困難や気分不良がなかったかを確認する。
