# 競合する美術館を参考にした改良計画

Optical Illusion をテーマにした競合の美術館が誕生しました。
自身の美術館と比較し、視覚的な見せ方、展示内容、操作方法など差異を確認し、この競合に負けない集客を得るには
どのような改修を行えば良いか、多角的に評価を行い、改修計画を作成したい。
その一歩目として、自身の美術館と競合美術館の差異を、実際に競合美術館を見て回って、リサーチ、レポートを作成してください。

# 競合美術館

## 鑑賞方法

http://localhost:4173 にアクセス(権限昇格必要。Chromeブラウザで Computer Useする)。
ロードが完了し、タイトルが表示されたら

クリックして入館します。

| 操作 | キー |
|---|---|
| 移動 | `W` `A` `S` `D` / 矢印キー |
| 視点 | マウス |
| 早歩き | `Shift` |
| ビュースポットへ視点スナップ | `E`(床の金色マーカー付近で) |
| 展示の操作(照明切替・調整・答え合わせ) | クリック / `F` / マウスホイール(操作対応の展示の近くで) |
| ヒントの表示 / 非表示 | `H` または画面下部のボタン |
| カーソル表示 | `Esc` |

## 展示ラインナップ

錯視は「特定の視点から見る」ことが本質のため、各展示の前には金色の床マーカー
(ビュースポット)があります。`E` キーで錯視が成立する視点にスナップできます。

- **ペンローズの三角形** — 特定視点でのみ閉じて見える不可能図形
- **不可能な立方体** — 奥の梁が手前の梁を突き抜けて見える立体交差
- **アナモルフォーシス** — 床と壁の歪んだ絵が視点から正しい像に立ち上がる
- **ペンローズの階段** — 無限に上り続けるように見える閉ループ階段(ボール付き)
- **エイムズの部屋** — 覗き窓から見ると普通の部屋。同じ大きさの人形が激変して見える(横のガラス面から種明かしが見える)
- **ホロウフェイス** — 凹んだ顔が飛び出して見え、視線を追いかけてくる
- **回転蛇錯視** — 完全な静止画なのに周辺視で回転して見える大型絵画
- **二つの真実(REAL / FAKE)** — 当館オリジナル。金の粒の雲が、南から見ると REAL、東から見ると FAKE と読める 2 視点アナモルフォーシス
- **色の恒常性の部屋**(操作可) — クリックで照明を切替。色付き照明下で普通に見えた果物の本当の色が現れる
- **ミュラー・リヤー調整実験**(操作可) — ホイールで線の長さを「同じ」に合わせ、クリックで答え合わせ。自分の目の誤差が % で分かる
- **2D 錯視ギャラリー** — チェッカーシャドー / ミュラー・リヤー / カニッツァの三角形 / エビングハウス / ツェルナー / カフェウォール

### 新館「FABLE ORIGINALS」

エントランスホール東側の開口から入れる増築棟。ここに並ぶ 5 展示は既知の錯視の
再現ではなく、Claude Fable 5 が知覚の原理から考案・設計したオリジナル作品です。

- **消える林** — 壁画の前に立つ 23 本の柱の林が、ビュースポットに立った瞬間まるごと壁画に溶けて消える。各柱の表面には「その柱がなければ見えたはずの景色」が視線の逆投影で 1 ピクセルずつ描いてある
- **嘘つきの鏡**(操作可) — 振り子の揺れまで完璧に「映る」鏡。だがあなたは映っていない。正体はガラスの奥に実物で作った鏡写しの双子の部屋。操作すると鏡像だけが物理法則を破る
- **絵の具のない黄色**(操作可) — 赤と緑の点だけで塗った絵が、離れると隣の「本物の黄色一色」と見分けがつかなくなる。ホイールで点の粒の大きさを変えて融合距離を確かめられる
- **呼吸する石像**(操作可) — 不動の石像が呼吸して見える。動いているのは周囲の球だけ。操作で動きを止めて種を確認できる
- **動きが生む幽霊**(操作可) — 静止中は平らな点の紋様。動いた瞬間、回転する立体の人影が立ち上がる。形の情報が「動きの中」にだけ存在する彫像

## 鑑賞方法の補助

3D空間の美術館を歩き回ることになるので、画像認識だけではなく、ソースレベルでの位置把握なども活用してください

## リサーチのルール

ソースレベルだけで判断するのはNG。必ず美術館での鑑賞体験としての視点を入れて調査すること。
調査結果項目毎に導き出した理由も併記すること
