PARALLAX 2.0 に対する課題点です

# 見え方のヒント

ダイアログが表示されることで鑑賞の妨げになっておりテンポが悪い

# 操作する

ウィンドウ表示されるとマウスでエイムしている最中にボタンを押すオペレーションが発生して煩雑

# 展示内容がわかりにくい

PARALLAX SIGNATURE HALL の展示はいずれもわかりにくい

# 鑑賞点近辺に立っても、操作するや見え方のヒントのボタンが出てこない

# 逆視差の窓

状態切り替えても影響がない

# エイムズの部屋

床のポリゴンが干渉している
２体のキャラクターの大きさがそもそも異なっているので
横から見ても部屋の歪みが感じられない

# チェッカーシャドウ

円柱の影が出ていないので意味がない

# CLASSICS LAB

全ての展示がウィンドウを開かないと中身が見れない作り
美術館で展示するものなので展示内容は3D空間上で直接見える必要がある

# 競合美術館と比較したときに

美術館での体験よりも説明を行うことに執着しすぎている
3D空間上で錯視を体感でき、その体感の補助として操作や説明の表示を行う

# PARALLAX 1.0の要素

要素を残すのではなく、美術館での体験へPARALLAXが持っていた強みの融合を行う

# 更なる改修にあたり

実在の美術館の展示の仕方やどのように流れを作っているかを調査した上で進める
