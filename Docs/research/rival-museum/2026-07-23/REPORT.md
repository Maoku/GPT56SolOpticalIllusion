# 競合美術館 調査レポート

調査日: 2026-07-23  
競合: Fable Optical Illusion Museum (`http://localhost:4173`)  
自館: PARALLAX (`http://127.0.0.1:4174`)  

## 1. エグゼクティブサマリー

競合 FABLE の最大の強みは、3D美術館を展示の容器ではなく、錯視を成立させる媒体にしていることだった。不可能な立方体は視点で形が閉じ、「消える林」は数歩の差で23本の柱が壁画へ消え、「嘘つきの鏡」は操作で鏡像だけが物理法則を破る。これらは一文・before/after・短い動画で他人へ伝えやすく、来館理由と共有理由が同じ作品の中にある（OBS-R-005, OBS-R-008〜013）。

自館 PARALLAX は別の軸で強い。タイトルで10展示と操作目的を説明し、3段階チュートリアル、ゾーン、マップ、進捗、全展示共通のヒント / 答え / リセット / 復帰、モーション軽減や品質設定を持つ。全10展示でこの循環を実操作でき、学習・回帰・包摂性は競合を上回った（OBS-S-001〜004, OBS-S-015, OBS-S-016）。

重み付き結果は FABLE 87.70、PARALLAX 83.44。差の本質は完成度の一方向な優劣ではなく、FABLE が「驚き・空間・展示幅・共有」で勝ち、PARALLAX が「迷いにくさ・操作理解・学習・アクセシビリティ」で勝つことにある。したがって次の改修で優先すべきは、競合のUIを模倣することではなく、自館の強い学習 / 包摂基盤を保ったまま、館内でしか成立しない象徴的オリジナルを1–2点作り、体験結果を共有可能な形にすることだ。

重要な制約として、計画書の厳密な網羅条件は未達である。競合はトップレベル16のうち成立 / 主要状態を実地確認できたのが13、2Dギャラリー内は4/6、操作展示は6/6。2D西壁2作品と基本展示3作品はソース確認に留まる。これらを直接評価へ加点せず、該当結論の確信度を下げた。自館10展示はすべて実表示し、操作循環を完了した。

詳細データは [訪問ログ](./visit-log.md)、[比較マトリクス](./comparison-matrix.md)、[ソース確認記録](./source-notes.md) を参照。親子連れをメインターゲットとする場合は、[親子連れ向けレポート](./REPORT_FAMILY.md) と [親子連れ向け比較マトリクス](./comparison-matrix-family.md) に再評価を分けた。

## 2. 調査条件と制約

同一の Chrome 150.0.7871.129、1200×734、ズーム100%、macOS 26.5.2で比較した。自館は高品質 / モーション軽減OFF。音は自動操作環境で正しく比較できないため採点対象外とした。自館 commit は `e1538819168de5320f39bbf0794ef37746bc1d5f`。

競合の初見ではデスクトップのキーボード / マウス / Pointer Lockを使い、系統鑑賞では記録との干渉を避けるため同じChromeで `?touch=1` を併用した。Pointer Lockの解除・再取得は通常来館者の鑑賞より、今回の自動記録で大きく現れるバイアスがある。自館は初回来館状態でタイトル→チュートリアル→自由探索→マップを通し、その後10展示の網羅確認に直接リンクを併用した。

調査者は1名。端末ロックによる約2時間の中断があり、初見自由鑑賞は約10分で計画目安20–30分に届かなかった。操作待機を含むため、完了時間 / 誤操作回数は定量比較に採用していない。スクリーンショットの一部にはChromeの既定ブラウザ通知バーがあり、コンテンツ実効高が揃わない。これらは外的妥当性と精密な時間比較を制限する。

## 3. 両館の来館体験フロー

### FABLE

タイトルは金色 / 黒の最小構成で、クリック入館後すぐ正面ホールと「新館 FABLE ORIGINALS」が見える。展示数や全体マップを先に説明せず、照明、金色マーカー、サインによって歩かせる。最初の60秒で「夜の美術館を自由に歩き、特定視点で錯視を見る」ことは伝わる一方、全体量や訪問済み状態は分からない（OBS-R-001〜004）。

展示前では、近接すると上部タイトル / ヒント / 視点案内が出る。床の金色マーカーと「視点」により成立位置へスナップし、操作展示では「操作」または `F`、wheel / `+/-` を使う。このループは不可能な立方体とミュラー・リヤーで明快だった。ただしアクティブ展示が視線ではなく距離優先になるため、回転蛇を見ていても近くの立方体名が出る場面があった（OBS-R-005, OBS-R-007, SRC-R-003）。

新館は入口サイン自体が誘引になる。内部5作品は視点消失、偽鏡、色混合、誘導運動、motion-defined form と形式が連続して変わり、増築棟名が「既知錯視とは違う」という期待を維持した。

### PARALLAX

タイトルは `PARALLAX`、タグライン、「10の錯視を歩いて、動かして、確かめる」、操作、設定を一画面に出す。入館後は移動→接近→ヒントを3段階で説明し、探索へ入る。競合より開始操作は多いが、「何をすればよいか」は明確（OBS-S-001, OBS-S-002）。

探索中は展示番号 / ゾーン / フォーカスが対象を特定し、マップには10展示と未体験 / 操作済み / 答え合わせ済みが表示される。全展示で `観察→ヒント→答え合わせ→リセット→終了` が同じ位置・キーで使え、10/10完了まで迷わず戻れた（OBS-S-003, OBS-S-004, OBS-S-015）。

一方、展示へ入ると多くが2D全画面の可変図形 / sliderへ切り替わる。館内を歩いた身体性と展示操作が分断され、競合のように「この位置に立ったから見えた」という記憶は残りにくい。

## 4. 評価軸別の比較

### 錯視の成立と視覚的インパクト — FABLE優位

競合は視点差・空間差が数歩で反転し、画像だけでも変化を説明できる。特に「消える林」は成立 / 位置ずれの2枚で、錯視、規模、実装の独自性が同時に伝わった。自館は数値やパラメータの理解が深いが、見た瞬間の劇的差は小さい（CMP-001）。

### 展示の幅と独自性 — FABLE優位

競合はトップレベル16＋ギャラリー6で、立体、部屋、壁画、点群、双子室、色点、静的絵画を行き来する。自館10作品は古典錯視を可変操作にした深さがある一方、画面形式の共通性が高く、オリジナルは2点（CMP-002）。

### 操作性とフィードバック — PARALLAX僅差優位

競合の物理状態変化は強烈だが、入力方法は展示ごとに `F` / click / wheel / `+/-` と変わり、現在値を出さない作品もある。自館は全展示で共通操作契約を保ち、数値、答え、reset、終了を一貫させる。ミュラー・リヤーでは競合の「27%」は共有しやすく、自館の「上160px / 下151px / 誤差9px」は調整を理解しやすかった（CMP-003）。

### 導入・ナビゲーション — PARALLAX優位

競合は空間誘導と発見の喜び、自館は全体像と完了支援に優れる。再訪や授業利用まで考えると、マップと進捗の価値が大きい。競合の新館サインは、自館のマップにない「行きたくなる目的地名」という別の強さを持つ（CMP-004）。

### 空間演出・ブランド — FABLE優位

競合は建築、照明、黒 / 金、展示台、マーカー、新館名が一つの館として連続する。自館もmint / magenta、問い、番号、zoneの一貫性は高いが、展示画面へ入ると空間から切れる（CMP-005）。

### 学習・種明かし — PARALLAX優位

競合は「鏡が嘘をつく」「像ではなく周囲が動く」など、操作自体が種明かしになる。自館は全展示で段階開示、WHY、数値 / 言語、再観察が保証される。学びの再現性は自館、驚きから理解へのドラマは競合（CMP-006）。

### 安定性 — ほぼ互角

当端末 / localhostでは両館とも描画停止や致命的破綻なし。競合にはPointer Lock復帰の記録摩擦、自館buildにはThree.js約1,068kB chunkの警告がある。低性能端末、モバイルGPU、ネットワーク条件は未検証（CMP-009）。

### アクセシビリティ — PARALLAX優位

自館は視点速度、音量、モーション軽減、品質、説明再表示、focus、タッチを利用者が選べる。競合にも大きなタッチボタンはあるが、今回のUI / CSSでは同等の設定を確認できなかった（CMP-007）。

### 再訪・共有性 — 性質が異なる

競合は作品そのものが共有素材、自館は直接リンク / 進捗が戻る仕組み。集客を目的にするなら自館に不足するのは後者ではなく、初見の他者へ送りたくなる1場面である（CMP-008）。

## 5. 共通展示の直接比較

### エイムズの部屋

自館は人物位置と鑑賞点をUIで切り替え、答えで台形構造を示すため原理が読みやすい。競合は3D部屋、覗き視点、横面からの種明かしを持つが、今回その成立視点を実地固定できずソース確認に留まった。現時点の仮判断は、身体性 / 驚きが競合、学習の確実性が自館。確信度は中。

### ミュラー・リヤー調整

競合では `+/-` 6回後に27%長く合わせた結果が赤く表示された。自館ではslider、pxライブ値、回答後の9px誤差が出た。競合は結果カードとして強く、自館は調整過程が明確。理想は、自館のライブ値 / resetに、競合の一言結果と再挑戦誘導を足すこと（OBS-R-013, OBS-S-005）。

### 明るさ・色

自館チェッカーシャドウは同一 `#747985` を明示し、色彩残響回廊は順応 / 無彩色 / 補色を段階化する。競合「色の恒常性」は橙色照明下で暖色へ近づいた4つの果物を、白色照明への一操作でピンク、薄紫、黄白、ベージュへ分離した。空間文脈の劇的反転は競合、物理値と原理の検証可能性は自館が強い（OBS-R-018, OBS-S-009, OBS-S-014）。

### 2D古典錯視

競合はギャラリーで複数原理を一目に比較でき、自館は各作品を個別に調整できる。どちらか一方ではなく、自館マップまたはロビーに「一覧でつまむギャラリー」を置き、興味を持った作品だけ深掘り画面へ入る二層構造が有望。

## 6. オリジナル展示の競争力

### 競合

1. **消える林**: 「23本の柱が、正しい位置では全部消える」。成立が瞬時、位置差が明瞭、静止画共有に強い。
2. **嘘つきの鏡**: 「鏡だと思った部屋の片側だけが法則を破る」。期待→破綻→種明かしの物語がある。
3. **動きが生む幽霊**: 「動いた時だけ人型が立つ」。短い動画と一文に向く。
4. **呼吸する石像**: 「像は止まっているのに呼吸する」。停止操作が因果確認になる。
5. **絵の具のない黄色**: 「赤と緑だけで黄色に見える」。原理は明快だが、今回の一段階操作は変化が弱く、数値不在で調整感が薄かった。

5作品は同じ新館名の下で形式が重複せず、「ORIGINALSを見るために来る」という理由を作っている。単なる作品数よりこの編集単位が強い。

### 自館

**視差の花**は花弁数、位相、追従量、視点位置を分解でき、触るほど理解が深まる。**色彩残響回廊**は順応→無彩色→補色を短い学習シーケンスにする。どちらも自館らしい「自分で確かめる」設計だが、結果が連続的 / 主観的で、before/afterの劇的な境界が弱い。

改善の焦点は作品数を5へ合わせることではない。自館のオリジナルに「一歩で反転する瞬間」「一文で話せるルール」「結果を持ち帰る形式」のどれかを与える方が競争力へ直結する。

## 7. 自館の優位点

- **全体像と完了感**: 10作品、3ゾーン、進捗状態をマップで読める。途中復帰と再訪目的を作れる（OBS-S-004, OBS-S-015）。
- **共通操作契約**: ヒント / 答え / reset / 終了を全10展示で完了できた。操作を学び直さない（OBS-S-015）。
- **段階的な学習**: 観察前に答えを出さず、必要時だけヒントとWHYを開き、回答後に再観察できる（SRC-S-004, SRC-S-005）。
- **定量フィードバック**: 実長px、誤差、hexなど、知覚と物理値の差を言語 / 数値にできる（OBS-S-005, OBS-S-007, OBS-S-009）。
- **包摂性と自己調整**: モーション軽減、速度、音量、品質、タッチ、focus、説明再表示が発見可能（OBS-S-016）。
- **共有 / 検証基盤**: 直接リンクとlazy moduleにより特定展示へ戻りやすく、回帰テストもしやすい（SRC-S-005, SRC-S-007）。
- **現条件での安定性**: 10展示の操作復帰に失敗せず、32テスト、型、lint、production buildが成功（OBS-S-017）。

## 8. 自館の主要ギャップ

1. **館内空間が錯視の成立条件になっていない**: 3D空間は探索ハブで、驚きは全画面パネル内に移る。競合の強作は位置と建築を切り離せない。
2. **オリジナルの来館理由が弱い**: 2作品とも調整 / 学習は深いが、「そこでしか見られない一瞬」として伝えにくい。
3. **展示形式の反復**: sliderと回答パネルが多く、原理は違っても操作リズムが似る。
4. **共有可能な結果が少ない**: 進捗はあるが、個人結果、before/after、短いリプレイ、共有用1枚がない。
5. **ブランドと展示空間の分断**: タイトル / HUDのブランドは強いが、展示へ入ると館内建築との関係が薄れる。
6. **一覧性と深掘りの接続不足**: 各展示は深いが、競合ギャラリーのように複数原理を一目で比較する場所がない。

## 10. 追加検証が必要な仮説

1. **象徴展示が想起 / 共有を増やすか**: 3–5名に現行オリジナルと空間prototypeを体験してもらい、24時間後の自由再生、共有意向、一文説明の一致率を比較する。
2. **チュートリアル3段階は丁寧すぎるか**: 現行と、歩きながら出すprogressive promptを比較し、最初の展示到達、誤操作、スキップ率を測る。
3. **結果カードが再挑戦を増やすか**: ミュラーのpx表示だけ / %＋カード＋再挑戦のA/Bで、2回目実行率と保存意向を測る。
4. **一覧→深掘りが滞在を伸ばすか**: 4作品のミニギャラリーから個別実験へ入るprototypeで、選択数と一作品あたり操作回数を見る。
5. **自由探索とマップの最適な提示時点**: 入館直後にマップを見せる / 迷った時だけ出す / 1展示後に解放する条件で、発見の喜びと網羅率を両方測る。
6. **競合未実地項目の補完**: エイムズ、ペンローズ三角形、アナモルフォーシス、2D西壁2作品を手動連続セッションで再訪し、現評価を更新する。
7. **低性能 / モーション条件**: 自館Three.js大chunkと両館の動的展示を、内蔵GPU相当、モバイル、reduced-motion ONで計測する。
8. **複数調査者での妥当性**: 錯視への既知度が異なる3–5名で、成立率、ヒント使用、記憶、共有意向を取り、今回1名の主観を補正する。
