# 親子連れをメインターゲットとした競合比較レポート

調査日: 2026-07-23  
対象: Fable Optical Illusion Museum / PARALLAX  
基礎資料: [一般来館者版レポート](./REPORT.md)  
採点詳細: [親子連れ向け比較マトリクス](./comparison-matrix-family.md)

## 1. 結論

来館のメインターゲットを親子連れに変えると、総合評価は **PARALLAX 87.60、FABLE 82.80** となり、自館が4.80点上回る。一般来館者版の FABLE 87.70、PARALLAX 83.44から順位が逆転した。

逆転の理由は、親子連れでは視覚的インパクトだけでなく、次の価値が大きくなるためである。

- 子どもへ操作を渡しても迷いにくい。
- 親に錯視知識がなくても、問いと答えを一緒に確かめられる。
- 疲れたり中断したりしても、現在地と残りが分かる。
- 動き、視点速度、画質を子どもの様子に合わせて調整できる。
- 家族内で結果を比べ、もう一度挑戦できる。

これらはPARALLAXのチュートリアル、共通操作、ヒントの段階開示、マップ、進捗、設定がすでに支えている（OBS-S-002〜004, OBS-S-015, OBS-S-016）。

ただし、子どもが最初の数分で歓声を上げる力はFABLEが明確に強い。「消える林」「嘘つきの鏡」「色の恒常性」は、長い説明なしに大きな変化が起き、親子の会話を即座に始められる（OBS-R-009, OBS-R-010, OBS-R-018）。したがって自館の家族戦略は、現在の学習・安心基盤を維持しつつ、最初の3分に親子で驚ける象徴展示を置くことが中心になる。

## 2. 想定する家族体験

本評価では、主に6〜12歳の子どもと保護者が、PCまたはタブレット1台を共有する場面を想定した。最初の滞在は15〜30分で、全10展示の制覇よりも「親子で3〜5個の錯視を試し、帰った後も一つ話せること」を成功条件とする。

理想的な1展示の流れは次の通り。

1. 画面が子どもへ短い問いを出す。
2. 親子が結果を予想する。
3. 子どもが操作する。
4. 親が必要なときだけヒントを開く。
5. 一緒に答え合わせする。
6. 親子の結果を比べるか、役割を交代して再挑戦する。

PARALLAXはすでに2〜5の基盤を持つ。追加すべきなのは、親子の役割を画面上で明示すること、短時間コース、家族内比較、そして導入の大きな驚きである。

## 3. 親子連れから見たFABLE

### 強み

**説明前に成立する驚き**が最大の強みである。

- 消える林: 「柱が全部消えた」と低学年でも反応しやすい。
- 嘘つきの鏡: 親が「鏡かな？」と問い、子どもが操作して正体を暴ける。
- 色の恒常性: 「本当は何色？」という身近な問いにできる。
- 呼吸する石像: 動いている対象を親子で当てられる。
- ミュラー・リヤー: 家族の誤差を%で比べられる。

新館の名称とサインも有効である。親が「まずオリジナルを見よう」と目的地を決めやすく、短時間でも強い展示へ到達できる（OBS-R-002）。

### 弱み

- 展示ごとに視点、`F`、wheel、`+/-`が変わり、子どもへ操作を渡すたびに親の説明が必要になりやすい。
- Pointer Lockと3D移動は、低年齢の子どもや普段ゲームをしない保護者には負担になり得る。
- マップと進捗が未確認で、「あといくつ」「どこまで見た」が分からない。
- 小さい補助文、モーション軽減や視点速度設定の未確認は、子どもの疲労や酔いへ対応しにくい。
- 強い作品が多い反面、親が原理を説明するためのWHYや数値が作品ごとに一定しない。

FABLEは「親子を一緒に驚かせる館」として強いが、「親子が交代しながら自力で学ぶ館」としては補助が必要と判断した。

## 4. 親子連れから見たPARALLAX

### 強み

**親子の共同実験を失敗させにくいこと**が最大の強みである。

- 3段階チュートリアルで、保護者が操作を理解してから子どもへ渡せる。
- 全10展示でヒント、答え合わせ、リセット、終了が共通し、役割交代しやすい。
- ヒントを自動表示せず、親子の予想時間を守る。
- マップで未体験 / 操作済み / 答え合わせ済みが分かり、時間に合わせて終了できる。
- モーション軽減、視点速度、音量、品質を保護者が調整できる。
- px誤差、hex値、構造図があり、親に事前知識がなくても説明を補える。

特にミュラー・リヤー、エビングハウス、チェッカーシャドウは、親子で予想と結果を比べる実験へ変換しやすい（OBS-S-005, OBS-S-007, OBS-S-009）。

### 弱み

- タイトル後に3画面の説明があり、子どもが驚く前に待つ時間がある。
- 多くの展示がslider中心で、子どもには「別の問題でも同じ操作」に感じられる可能性がある。
- 視差の花は自由度が高い反面、低年齢には「何を目指せば成功か」が曖昧。
- 色彩残響回廊は注視時間と個人差があり、見えない子どもが失敗と感じる可能性がある。
- 進捗は個人単位で、親と子の予想や結果を並べて残せない。
- 競合の消える林に相当する、一操作で画面全体が反転する象徴展示がない。

## 5. 年齢帯による違い

### 6〜8歳

重視すべきは、大きな視覚変化、短い一文、大きい操作対象、即時フィードバックである。この年齢ではFABLEの象徴展示が強い一方、移動と細かい文字は保護者依存になる。PARALLAXは操作一貫性で有利だが、px、hex、位相といった語を子ども向けに言い換える必要がある。

推奨表現例:

- `誤差 9 px` → `あと少し！ ほんとうの長さとの差は9`
- `#747985` → `AとBは、コンピューターではまったく同じ色`
- `層の位相` → `花びらのずれ`

### 9〜12歳

数値、競争、再挑戦、家族比較が効きやすい。PARALLAXのsliderと答え合わせを「親子チャレンジ」に変換しやすく、自館の優位が最も大きい層と推測する。FABLEの空間展示は強い報酬になるため、3D視点の象徴展示をコース終盤へ置くとよい。

### 保護者

保護者は、操作説明だけでなく、終了時点、動きの負荷、教育価値、子どもへ何と声をかけるかを必要とする。PARALLAXは設定と進捗で安心を作れている。さらに各展示へ「聞いてみよう: どちらが長く見える？」のような保護者用一文を付ければ、知識の有無に依存せず会話を始められる。

## 6. 推奨する家族向けコース

### 15分・はじめてコース

1. チェッカーシャドウ — 即答しやすい二択。
2. ミュラー・リヤー — 親子で調整結果を比較。
3. 新しい空間型シグネチャー展示 — 最後に大きな驚き。

狙いは、`予想する→操作する→比べる→歓声で終わる` の4段階を15分で完成させること。

### 30分・じっくり実験コース

1. チェッカーシャドウ
2. エビングハウス
3. エイムズの部屋
4. 運動誘発盲または色彩残響回廊
5. 空間型シグネチャー展示

動きに敏感な子どもには、4をネッカーキューブへ置き換える。コース開始時に「動き少なめ」を選べると保護者の判断負荷を減らせる。

## 7. 親子ターゲットでの最優先改善

| 優先 | 改善機会 | 期待効果 | 証拠確信度 |
| --- | --- | --- | --- |
| P0 | **15分 / 3展示の親子コースをタイトル直後に選べるようにする** | 短時間満足、離脱防止 | 高 |
| P0 | **各展示を「予想→子どもが操作→一緒に答え」の役割表示へする** | 自然な会話と交代 | 高 |
| P0 | **最初または最後に、一操作で大きく反転する空間型展示を置く** | 子どもの想起、口コミ | 高 |
| P0 | **子ども向け一文と保護者向けWHYを二層化する** | 読解差への対応 | 中 |
| P1 | **親 / 子の結果を並べるファミリーチャレンジ** | 再挑戦、家族内会話 | 中 |
| P1 | **3展示ごとのスタンプと、コース完了カード** | 達成感、共有 | 中 |
| P1 | **タイトル画面からモーション軽減 / 動き少なめコースを選択** | 安心、安全側の選択 | 高 |
| P1 | **マップに推奨順、残り時間、休憩 / 終了地点を表示** | 保護者の進行支援 | 中〜高 |
| P2 | **低学年向けふりがな、読み上げ、簡単ことば** | 対象年齢拡大 | 低〜中 |

家族向けの最重要施策は、展示数を増やすことではなく、**既存の操作契約を親子の役割契約へ変えること**である。自館がすでに持つ問い、ヒント、答え、リセットへ「だれが何をするか」を一行足すだけでも、単独利用の実験から共同体験へ意味を変えられる。

## 8. 集客メッセージへの示唆

親子向け訴求では「錯視を学べる」だけでは弱い。教育価値を前面に出しすぎると、子どもに宿題の印象を与える可能性がある。

有望な価値提案は次の組み合わせである。

- **遊びの約束**: `親子で目を疑う15分`
- **会話の約束**: `同じものを見ても、家族で答えが違う`
- **学びの約束**: `予想して、動かして、なぜかを確かめる`
- **安心の約束**: `短いコース、動き少なめも選べます`
- **持ち帰りの約束**: `家族の錯視結果カードを作ろう`

FABLEの写真映えに対抗するには、単に展示画像を派手にするのではなく、親子2人の結果差や一緒に完成させたコースを共有物へする方が、PARALLAX固有の強みと一致する。

## 9. 検証が必要な事項

本版は既存の成人1名調査からの再評価であり、親子の実体験を直接観察していない。実装判断前に、6〜8歳と9〜12歳を含む親子3〜5組で次を確認する。

1. タイトルから最初の展示まで子どもの関心が続くか。
2. 親が説明しすぎず、子どもへ操作を渡せるか。
3. 15分後、子どもが一つの展示を自分の言葉で話せるか。
4. sliderが低学年にも操作できるか。
5. 3D移動や動的展示で酔い、疲労、離脱が起きないか。
6. 親子結果カードが再挑戦と共有意向を高めるか。
7. 保護者が「遊び」と「学び」の両方へ満足するか。

この検証が済むまでは、年齢別の可読性とモーション負荷に関する評価の確信度を中以下とする。一般版と共通する証拠、未実地項目、ソース裏付けは [訪問ログ](./visit-log.md) と [ソース確認記録](./source-notes.md) を参照。
