# 親子連れ向け比較マトリクス

本書は [一般来館者向け比較](./comparison-matrix.md) と同じ観察証拠を、親子で1台の画面を一緒に見る利用場面へ再配点した評価版である。

## 想定する親子像

- 子ども: 主に6〜12歳。錯視の事前知識はなく、長文より変化と操作から理解する。
- 保護者: 子どもの安全、迷いにくさ、学び、短時間での満足を重視する。
- 利用形態: 1台のPC / タブレットを共有し、保護者と子どもが予想・操作・答え合わせを交代する。
- 滞在時間: まず15〜30分。全展示制覇より「家族で3〜5個の驚きを共有できたか」を重視する。

実際の子どもを含むユーザーテストは未実施である。可読性、理解年齢、酔いやすさに関する点数は、成人1名の観察からの仮説として扱う。

## 親子向け重要比較

### CMP-F-001 — 子どもの最初の笑顔を作る力

- 観察事実: FABLEの消える林、嘘つきの鏡、色の恒常性は、一操作または数歩で画面が大きく変わる。PARALLAXはslider調整後に意味が分かる展示が多い。
- 親子への影響: 低年齢ほど説明前の視覚変化に反応しやすいと推測され、導入のつかみはFABLEが強い。
- 判断理由: 「消えた」「鏡じゃない」「色が違った」と短い言葉で子どもが反応できる。
- 証拠 ID: OBS-R-009, OBS-R-010, OBS-R-018, OBS-S-013
- 確信度: 中。子ども実査が必要。

### CMP-F-002 — 親子で予想して交代できるか

- 観察事実: PARALLAXは全展示で問い、操作、ヒント、答え合わせ、リセットが同じ順序。FABLEは展示ごとに視点、`F`、wheel、`+/-`が変わる。
- 親子への影響: PARALLAXでは「親が問題を読む→子が動かす→一緒に答えを見る」という役割分担を作りやすい。
- 判断理由: 操作を交代しても、次の展示で学び直す量が少ない。
- 証拠 ID: OBS-R-003, OBS-R-011, OBS-R-013, OBS-S-015
- ソース裏付け: SRC-R-004, SRC-S-005
- 確信度: 高

### CMP-F-003 — 保護者が迷わず伴走できるか

- 観察事実: FABLEは空間誘導が強い一方、マップと進捗は未確認。PARALLAXはゾーン、10展示一覧、3段階進捗、10/10完了表示を持つ。
- 親子への影響: PARALLAXでは保護者が残り時間に合わせて「あと1個」「今日はここまで」を決めやすい。
- 判断理由: 親子の中断は興味の移動、疲労、呼びかけで起きやすく、現在地と復帰先が見える価値が高い。
- 証拠 ID: OBS-R-004, OBS-S-004, OBS-S-015
- ソース裏付け: SRC-S-003
- 確信度: 高

### CMP-F-004 — 学びが親の負担にならないか

- 観察事実: PARALLAXはWHY、px誤差、hex値、構造図を表示する。FABLEは物理的な種明かしが強いが、作品によって説明の深さが異なる。
- 親子への影響: PARALLAXでは保護者に錯視知識がなくても、画面の説明を一緒に読める。FABLEは保護者が先に理解できれば会話が大きく弾む。
- 判断理由: 教える人 / 教わる人に固定せず、親子とも驚いてから答えを確かめられる自館の順序が家族利用に合う。
- 証拠 ID: OBS-R-009, OBS-R-012, OBS-R-013, OBS-S-005〜015
- 確信度: 高

### CMP-F-005 — 動きに敏感な子どもへの配慮

- 観察事実: FABLEではモーション軽減、視点速度、描画品質のUIを確認できなかった。PARALLAXはこれらを設定画面に出す。
- 親子への影響: 保護者が子どもの様子を見て負荷を下げられるPARALLAXが安全側。
- 判断理由: 3D移動、回転背景、点群運動は個人差が大きく、保護者が即時調整できることが重要。
- 証拠 ID: OBS-R-014, OBS-S-011, OBS-S-016
- ソース裏付け: SRC-R-006, SRC-S-006
- 確信度: 中。子どもの実機評価が必要。

### CMP-F-006 — 15分だけでも「来てよかった」になるか

- 観察事実: FABLEは入館直後から新館と複数展示が見え、強い作品を1〜3点見るだけでも印象が残る。PARALLAXはチュートリアル後、個別実験を順に深掘りする。
- 親子への影響: 短時間満足はFABLEが上。PARALLAXは保護者向けに3作品 / 15分の推奨コースを出す余地がある。
- 証拠 ID: OBS-R-002, OBS-R-005, OBS-R-010, OBS-S-002, OBS-S-004
- 確信度: 高

## 家族ユーザーテストの必須項目

次の判断は現調査だけでは確定できないため、6〜8歳、9〜12歳を含む親子3〜5組で確認する。

1. 子どもが保護者の説明なしで最初の操作を始められるか。
2. 親子が自発的に操作を交代するか、一人が占有するか。
3. 15分後に子どもが展示を一文で説明できるか。
4. ヒントが「親の答えの先回り」にならず、会話を助けるか。
5. 3D移動や運動展示で酔い・疲れ・離脱が出ないか。
6. マップ、スタンプ、結果カードのどれが再挑戦を促すか。
7. 保護者が教育価値と遊びの価値を両方感じるか。
