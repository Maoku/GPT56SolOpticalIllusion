## 重要比較

### CMP-001 — 空間を錯視の媒体にできているか

- 観察事実: 競合の不可能な立方体、消える林、嘘つきの鏡は、来館者の位置と建築 / 立体物が成立条件。自館は3D館内から展示へ入ると主に2D全画面体験になる。
- 体験への影響: 競合は「その場へ行った」身体記憶と写真を残しやすい。自館は調整・解説に集中しやすいが、館内を歩く必然性が薄くなる。
- 判断理由: 最も強かった競合3作品はいずれも通常スクリーンだけでは置き換えにくかった。
- 証拠 ID: OBS-R-005, OBS-R-009, OBS-R-010, OBS-S-003
- ソース裏付け: SRC-R-002, SRC-R-003, SRC-S-005
- 確信度: 高

### CMP-002 — 展示幅と独自性

- 観察事実: 競合はトップレベル16＋2Dギャラリー内6。新館5作品に加え「二つの真実」も固有作品。自館は10展示、オリジナル2。
- 体験への影響: 競合は「次は形式が変わる」期待を維持し、滞在価値が高い。自館は各作品を深く操作できるが、slider中心の反復を感じやすい。
- 判断理由: 数量だけでなく、立体、壁画、運動点群、双子室、色混合、像と球という形式差がある。
- 証拠 ID: OBS-R-006, OBS-R-008〜012, OBS-S-005〜014
- ソース裏付け: SRC-R-002, SRC-R-005, SRC-S-001
- 確信度: 高

### CMP-003 — 操作と結果の理解

- 観察事実: 競合ミュラー・リヤーは `+/-`→回答で「27%」を返す。自館はslider中にpxを表示し、回答で実長 / 誤差を返す。自館10展示は共通のヒント / リセット / 答え / 終了を持つ。
- 体験への影響: 競合の結果は会話しやすく、自館は試行錯誤の因果を追いやすい。
- 判断理由: 入力の発見性・数値の即時性・復帰可能性を合わせると自館が僅差で上。
- 証拠 ID: OBS-R-013, OBS-S-005, OBS-S-015
- ソース裏付け: SRC-R-004, SRC-S-005
- 確信度: 高

### CMP-004 — 自由探索と網羅支援

- 観察事実: 競合は入口の眺望、照明、金色マーカー、新館サインで探索を誘うが、マップ / 進捗は未確認。自館はゾーン、フォーカス、マップ、3段階進捗を持つ。
- 体験への影響: 競合は発見の喜び、自館は迷いにくさと完了感が強い。
- 判断理由: 「次へ行きたい」と「全部見たい」を分けると、前者は競合、後者は自館。
- 証拠 ID: OBS-R-002〜004, OBS-S-002〜004, OBS-S-015
- ソース裏付け: SRC-R-002, SRC-S-002, SRC-S-003
- 確信度: 高

### CMP-005 — ブランド

- 観察事実: 競合は金色 / 黒、展示照明、増築棟名まで一貫。自館は `PARALLAX`、mint / magenta、問いかけ、番号 / zone / original表記が一貫。
- 体験への影響: 競合は高級な夜間美術館、自館は実験室的で親しみやすい学習館として記憶される。
- 判断理由: 両館とも一貫するが、競合は空間全体までブランド表現が連続する。
- 証拠 ID: OBS-R-001, OBS-R-002, OBS-S-001, OBS-S-003
- ソース裏付け: SRC-R-006, SRC-S-004
- 確信度: 高

### CMP-006 — 学習と種明かし

- 観察事実: 競合は操作で物理状態が変わる種明かしが強い。自館は全展示でヒントの WHY、回答、リセットを同じ順序で使える。
- 体験への影響: 競合は驚きから理解へ飛躍し、自館は理解を確実に積み上げる。
- 判断理由: 全展示の再観察可能性と数値 / 言語の説明密度で自館が上。
- 証拠 ID: OBS-R-009, OBS-R-012, OBS-R-013, OBS-S-005〜015
- ソース裏付け: SRC-R-004, SRC-S-004, SRC-S-005
- 確信度: 高

### CMP-007 — アクセシビリティ

- 観察事実: 競合はタッチUIを持つが、モーション軽減、品質、視点速度、進捗、明示的focus表示は未確認。自館は設定UI、タッチ、キーボード、focus-visible、コントラスト / モーション配慮を持つ。
- 体験への影響: 自館は利用者が負荷を選び、途中で操作説明へ戻れる。
- 判断理由: 実装存在だけでなく設定パネルから発見できたため、自館の明確な優位。
- 証拠 ID: OBS-R-014, OBS-S-016
- ソース裏付け: SRC-R-006, SRC-S-006
- 確信度: 高

### CMP-008 — 再訪・共有

- 観察事実: 競合の消える林、嘘つきの鏡、幽霊、ミュラー結果はbefore/afterや一文にしやすい。自館は直接リンクと進捗が再訪を支えるが、オリジナル2作品の静止画フックは相対的に弱い。
- 体験への影響: 競合はSNS / 口コミ、自館は継続鑑賞 / 授業利用に向く。
- 判断理由: 共有の「素材」は競合、戻る「仕組み」は自館。
- 証拠 ID: OBS-R-008〜013, OBS-S-004, OBS-S-013, OBS-S-014
- ソース裏付け: SRC-S-003, SRC-S-007
- 確信度: 高

### CMP-009 — 安定性

- 観察事実: 両館とも現端末で致命的な描画破綻なし。競合はPointer Lock記録摩擦、自館はproduction buildのThree.js大chunk警告あり。
- 体験への影響: 現行デスクトップでは差が小さい。低性能端末 / ネットワークでは未検証。
- 判断理由: localhost 1台の結果を一般化しない。
- 証拠 ID: OBS-R-015, OBS-S-017
- ソース裏付け: SRC-R-007, SRC-S-008
- 確信度: 中

## 共通テーマの直接比較

| テーマ | 競合 | 自館 | 判断 |
| --- | --- | --- | --- |
| エイムズの部屋 | 3D部屋、固定視点、横から構造を種明かし（今回の成立視点はソース確認のみ） | 人物レール / 鑑賞点 / 俯瞰をUIで切替 | 身体性は競合、学習の明示性は自館。競合実地未完のため確信度中 |
| ミュラー・リヤー | `+/-` / wheel、結果27%、一言で共有可能 | slider、実長px、誤差9px、調整中も値が見える | 共有は競合、操作理解は自館 |
| 明るさ・色 | 色の恒常性は橙 / 白照明を一操作で切替、2D checkerは一覧展示 | checkerで同一hex表示、色彩残響で順応シーケンス | 空間文脈の反転は競合、数値 / 原理の検証可能性は自館 |
| 2D古典錯視 | 6作品をギャラリーで一覧 | 該当作品を個別画面で可変操作 | 一覧性は競合、一作品の深さは自館 |
| オリジナル | 新館5＋二つの真実。空間 / 物理 / 運動の形式が多い | 視差の花、色彩残響回廊。調整 / 学習が細かい | 来館理由と共有性は競合が大きく上 |
| 館内誘導 | マーカー、照明、新館サイン | フォーカス、zone、マップ、進捗 | 偶然の発見は競合、完了支援は自館 |

自動操作の待機が混ざるため、完了時間と誤操作数は比較指標に採用しなかった。操作結果と必要ステップのみを比較した。
