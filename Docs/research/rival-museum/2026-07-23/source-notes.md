# ソース確認記録

調査日: 2026-07-23  
対象: 競合 `http://localhost:4173` / 自館 `http://127.0.0.1:4174`  
原則: 体験ログを先に固定し、その後にソースを確認した。ソースだけで存在を確認した展示・機能は体験評価へ加点していない。

## 競合

競合はローカル配信された `assets/index-CFy-2ix_.js`（minify 済み、source map なし）と `assets/index-*.css`、実行時 UI を確認した。行番号を安定して指せない一行 bundle のため、識別子・表示文言・座標を併記する。

### SRC-R-001 — 初期位置と入力

- 確認内容: 初期位置は概ね `(0, 1.6, 12.5)`。WASD、Shift、Pointer Lock、タッチ用ジョイスティックと視点ドラッグの分岐がある。
- 体験への現れ方: 入館直後に正面ホールと東側の「新館 FABLE ORIGINALS」サインを見通せた。一方、Pointer Lock の解除・再取得は記録操作と競合し、系統鑑賞では同一 Chrome の `?touch=1` を併用した。
- 対応観察: OBS-R-001, OBS-R-002, OBS-R-004
- 確信度: 高

### SRC-R-002 — トップレベル展示と配置

- 確認内容: 基本展示 10、2D ギャラリー 1、新館 5 の計 16 エントリを確認した。主要座標は、不可能な立方体 `(-5,-2)`、回転蛇 `(-6,6.78)`、色の恒常性 `(6.5,5.9)`、ミュラー・リヤー `(-6.5,11)`。新館は消える林 `(34.84,11)`、嘘つきの鏡 `(26,3.5)`、絵の具のない黄色 `(25.5,20.6)`、呼吸する石像 `(19.5,17.5)`、動きが生む幽霊 `(16.6,5.5)`。
- 体験への現れ方: 初見でも新館入口は発見できたが、館全体の一覧・進捗 UI は見つからず、奥の展示を網羅するには位置情報が必要だった。
- 対応観察: OBS-R-002, OBS-R-006, OBS-R-009, OBS-R-010, OBS-R-011, OBS-R-017, OBS-R-018
- 確信度: 高

### SRC-R-003 — 接近判定とビュースポット

- 確認内容: 展示ごとの `triggerRadius` 内でアクティブ展示を選び、複数候補では root への距離を使う。`snapToViewSpot` は利用可能な view spot のうち近いものへ視点を補間する。
- 体験への現れ方: 金色マーカーと「視点」ボタンで不可能な立方体・ミュラー・リヤーが明確に成立した。一方、回転蛇を見ていても近い立方体のタイトルが上部に出る場面があり、「見ている対象」と「近い対象」がずれることがあった。
- 対応観察: OBS-R-005, OBS-R-007, OBS-R-013
- 確信度: 高

### SRC-R-004 — 操作展示の状態遷移

- 確認内容: 色の恒常性はクリック / `F` で照明切替、ミュラー・リヤーは wheel またはタッチの `+/-` で長さ調整してクリック / `F` で誤差表示。嘘つきの鏡は左右の物理挙動を破綻させ、絵の具のない黄色は点サイズを変更、呼吸する石像と動きが生む幽霊は動作の停止 / 再開を行う。
- 体験への現れ方: 6展示すべてで実操作を確認した。色の恒常性では橙色照明下で同系色に見えた果物が、白色照明へ切り替えるとピンク、薄紫、黄白、ベージュへ分離した。
- 対応観察: OBS-R-008〜OBS-R-013, OBS-R-018
- 確信度: 高

### SRC-R-005 — 2D ギャラリーの内訳

- 確認内容: 北壁にチェッカーシャドー、ミュラー・リヤー、カニッツァ、エビングハウス、西壁にツェルナー、カフェウォールの計6作品。
- 体験への現れ方: 北壁4作品は同時に一覧でき、立ち止まらずに幅を感じられた。西壁2作品は実見証拠を固定できず、ソース確認に留まる。
- 対応観察: OBS-R-006
- 確信度: 北壁4作品は高、西壁2作品は中

### SRC-R-006 — UI・アクセシビリティの実装範囲

- 確認内容: golden-on-dark の HUD、デスクトップ操作説明、68px（狭幅では56px）のタッチボタンを確認した。調査対象 CSS では `:focus-visible`、`prefers-reduced-motion`、専用の進捗・マップ・設定 UI を確認できなかった。
- 体験への現れ方: 雰囲気は強いが、小さい補助文と動きの多い展示に対する代替設定は来館者から発見できなかった。「存在しない」と断定するのではなく、今回の配信 bundle / UI で未確認とする。
- 対応観察: OBS-R-001, OBS-R-003, OBS-R-014
- 確信度: 中

### SRC-R-007 — 配信単位

- 確認内容: メイン JS は約 591,965 bytes、CSS は約 4,866 bytes。メイン JS は単一 bundle として配信され、source map は見つからなかった。
- 体験への現れ方: 調査機ではタイトルから館内表示まで目立つ待ち時間はなかった。ただし単一端末・localhost のため、ネットワーク環境での性能一般化はしない。
- 対応観察: OBS-R-015
- 確信度: 高

## 自館

### SRC-S-001 — 展示カタログ

- 確認内容: [`src/exhibits/exhibitCatalog.ts`](../../../../src/exhibits/exhibitCatalog.ts) に10展示、座標、操作文、ヒント、接近距離が定義される。オリジナルは「視差の花」「色彩残響回廊」の2作品。
- 体験への現れ方: 10展示すべてで固有の問いと操作説明が表示されたが、競合の16トップレベル＋ギャラリー6作品より量・空間形式が少ない。
- 対応観察: OBS-S-005〜OBS-S-014
- 確信度: 高

### SRC-S-002 — 発見・接近条件

- 確認内容: [`src/scene/focus.ts`](../../../../src/scene/focus.ts) は `interactionDistance` と前方内積 `0.5` を使い、近さだけでなく視線方向も要求する。
- 体験への現れ方: 探索 HUD の展示名は見ている対象と一致しやすい。反面、接近していても正面へ向ける必要があるため、初回はチュートリアルが重要になる。
- 対応観察: OBS-S-003, OBS-S-004
- 確信度: 高

### SRC-S-003 — 体験状態と進捗

- 確認内容: [`src/state/useMuseumStore.ts`](../../../../src/state/useMuseumStore.ts) は `unvisited` / `interacted` / `revealed`、タイトル・探索・展示 stage、ヒント・マップ・設定・チュートリアル overlay を保持する。
- 体験への現れ方: マップで未体験 / 操作済み / 答え合わせ済みを見分けられ、10展示完了後のメッセージまで確認できた。
- 対応観察: OBS-S-004, OBS-S-015
- 確信度: 高

### SRC-S-004 — 導入とヒントの段階開示

- 確認内容: [`src/ui/StartScreen.tsx`](../../../../src/ui/StartScreen.tsx) は10展示と操作をタイトルで説明し、[`src/ui/TutorialOverlay.tsx`](../../../../src/ui/TutorialOverlay.tsx) は移動→接近→ヒントの3段階。ヒントは自動表示しない。
- 体験への現れ方: ブランドと「何をする場所か」は競合より明示的。入館後すぐ歩ける競合に比べ、探索開始まで3操作増える。
- 対応観察: OBS-S-001, OBS-S-002
- 確信度: 高

### SRC-S-005 — 展示 UI の共通契約

- 確認内容: [`src/exhibits/ExhibitExperience.tsx`](../../../../src/exhibits/ExhibitExperience.tsx) は展示 module を lazy load し、ヒント、リセット、答え合わせ、終了を共通配置する。
- 体験への現れ方: 全10展示で「観察→ヒント開閉→答え合わせ→リセット→探索復帰」を実操作できた。学習手順は安定するが、各展示の操作感は似やすい。
- 対応観察: OBS-S-005〜OBS-S-015
- 確信度: 高

### SRC-S-006 — 設定と包摂性

- 確認内容: [`src/ui/SettingsPanel.tsx`](../../../../src/ui/SettingsPanel.tsx) に視点速度、音量、モーション軽減、描画品質、説明再表示。[`src/styles/global.css`](../../../../src/styles/global.css) に `:focus-visible`、44px最小ターゲット、モバイル調整、`prefers-reduced-motion` / `prefers-contrast` 系の配慮がある。
- 体験への現れ方: 設定が UI 上で読め、キーボード / タッチ / 動きへの配慮を利用者が選べる。
- 対応観察: OBS-S-016
- 確信度: 高

### SRC-S-007 — 直接リンクと初期化

- 確認内容: [`src/app/bootstrap.ts`](../../../../src/app/bootstrap.ts) は `?exhibit=<id>` を解釈し、指定展示を直接開く。
- 体験への現れ方: 系統鑑賞で全展示を同条件表示できた。共有・再訪・回帰テストに有利だが、通常来館時の自然発見性とは分けて評価した。
- 対応観察: OBS-S-005〜OBS-S-014
- 確信度: 高

### SRC-S-008 — 品質検証

- 確認内容: 2026-07-23 に `npm test -- --run`（9 files / 32 tests）、`npm run typecheck`、`npm run lint`、`npm run build` を実行し成功。build は Three.js chunk 約1,068 kB（gzip 約296 kB）のサイズ警告あり。アプリ側の初期 deploy payload 推定は gzip 約0.31 MB。
- 体験への現れ方: 実地で描画停止や操作不能は起きなかったが、低性能端末での GPU / モーション負荷は別検証が必要。
- 対応観察: OBS-S-017
- 確信度: 高
